A GUIDE TO THE OBSERVATORY

Inspect a measurement.
Replay an experiment.

  1. Run a prompt. The selected PyTorch backend records real attention and residual activations at each generated token. Cortex Tiny is the offline fixture; Qwen3 uses local pretrained weights.
  2. Select a node. Each node is one token’s post-block residual vector. Layer depth and token position are schematic coordinates, not learned embedding geometry.
  3. Choose a head. Arcs go from the selected query to the keys it attends to. The inspector shows the complete row, even when a threshold hides links.
  4. Scrub the recording. Each step is a complete forward pass before its predicted token becomes the next input. Playback pacing is independent of measured inference time.
  5. Try an intervention. Run the same prompt with “Zero selected head output.” This zeros that head’s weighted value output, leaving attention probabilities intact. Compare the recorded first-frame residual and prediction with a baseline.
  6. Export your evidence. JSON contains the actual captured tensors, model hash, request and timing. Import it later without rerunning the model.

Cortex Tiny has an original, limited corpus; unknown words become <unk>. Qwen3 uses pretrained weights and selected blocks/heads; its bar plot shows sampled channels while node norms use the full vector. Attention is not a causal explanation.
