# Cortex Tiny v1 model card

Purpose: a transparent fixture for inspecting a real causal transformer. It is not a general-language assistant, benchmark model, semantic truth source, or interpretability discovery result.

## Architecture and provenance

Original PyTorch implementation in `backend/model.py`: 3 pre-norm decoder blocks, 4 attention heads per block, width64, MLP width256/GELU, learned token/position embeddings, context48, final LayerNorm and untied output projection. No dropout, pretrained parameters, external model code or KV cache. 158,912 float32 parameters, 45-token lowercase word/punctuation vocabulary with `<pad>`, `<bos>`, `<eos>`, `<unk>`. Greedy argmax includes all vocabulary classes; EOS stops generation. Unknown input words are explicitly mapped to `<unk>`.

Checkpoint: `examples/tiny-transformer.pt`, 649,648bytes, SHA-256 `4cc6aa28ecb40e80aea222e3bba2fdd80ab8d1bed7c29f654a8495cb9529ad55`. Loading uses the fixed local path, hash verification, `torch.load(weights_only=True)`, strict parameter shapes and finite-value checks. There is no checkpoint-upload API.

Original MIT corpus generated by `backend/corpus.py`: colors/objects/verbs plus five model-inspection sentences. After deduplication:329 unique sequences, seeded shuffle23, every seventh sequence held out (47), remaining282 train. Vocabulary is built from the full authored grammar; held-out evaluation measures unseen **sentences within the same grammar**, not unseen vocabulary or broad-domain generalization. Templates and vocabulary overlap across splits. This is a deliberately easy educational task.

## Training and evaluation

`python scripts/train.py`: CPU float32, Torch2.6.0+cu124 installed but no CUDA computation; one CPU thread, seed23, AdamW lr0.003/weight_decay0.01, batch64, 500 updates. Next-token cross-entropy excludes pad targets. See `examples/model.json` for corpus hash and exact configuration.

The test suite recomputes held-out metrics directly from the checkpoint. Training loss alone is not the learning claim. The task includes intrinsically ambiguous color/verb continuations, and accuracy does not certify natural-language competence. Maximum context is an architectural bound; training examples are substantially shorter, so long prompts are a stress test, not a quality guarantee.

## Capture and intervention

Record each full prefix forward pass before appending its greedy prediction. Attention is masked post-softmax `[head][query][key]`, before optional head-output ablation. Residual is the post-block token vector after attention and MLP residual additions, before the next block/final norm. Norm is channelwise L2. Full bounded tensors are recorded as finite JSON numbers; no top-k truncation of attention. Top5 next-token probabilities are a separate, explicitly partial distribution.

Ablation zeros a selected head's `probabilities @ V` output before concatenation/projection, leaving that block's attention probabilities unchanged; downstream tensors may change. No claim that every ablation changes argmax, or that an attention link establishes causal importance.

## Reproducibility and license

Recordings replay serialized values exactly on any supported browser. Rerunning inference/training can differ slightly across libraries, platforms or devices; the stored checkpoint hash and runtime identify evidence. CPU tests use explicit tolerances for cross-runtime numeric comparison. Original code/corpus/fixture MIT; dependencies keep their own notices.
